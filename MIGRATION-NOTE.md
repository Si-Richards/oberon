# Migration note

The original 7 August 2026 Spot/Testnet prototype is preserved in Git history and on the `legacy-spot-testnet-2026-08-07` branch. Oberon v0.9.1 replaces `main` with the USD-M Futures signal-research architecture.

The GitHub repository did not contain the later v0.9.0 runtime source that produced the supplied Futures reports, so v0.9.1 is a clean, self-contained reconstruction around the established report interfaces and research goals rather than a byte-for-byte patch of that unavailable source tree.
